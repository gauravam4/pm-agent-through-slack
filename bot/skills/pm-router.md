# PM skill router

Pick the single best next skill, load it, then follow it.

## Themes → skills

1. **PRD / requirements** → `prd-development` (full workflow) or `cmd-write-prd` (chained command). Outline-only asks still use `prd-development` and return a structured outline with assumptions tagged.
2. **Prioritization** → `prioritization-advisor` or `cmd-prioritize`.
3. **Roadmap** → `roadmap-planning` or `cmd-plan-roadmap`.
4. **Discovery / interviews** → `discovery-interview-prep`, `discovery-process`, or `cmd-discover`.
5. **Stories** → `user-story`, `user-story-splitting`, `epic-breakdown-advisor`.
6. **Strategy / intel** → `cmd-strategy`, `competitive-analysis-process`, `company-research`.
7. **Leadership transition** → `cmd-leadership-transition`.

## Rules

- Prefer a workflow/command skill over inventing a new process.
- One clarifying question only when a blocking input is missing.
- Otherwise produce a concrete draft with **Assumption** and **Open question** labels.
